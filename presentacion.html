La web actual: 6 problemas concretos

Problema

  • Portada llena de licitaciones y avisos administrativos
  • Oferta educativa oculta en menú desplegable de 3 niveles
  • Textos extensos cortados por CSS (70px)
  • Carrusel mezclado, sin CTA para aspirantes
  • Sin "Quiero ser aspirante": no hay ruta de conversión
  • Sitio pesado: Bootstrap 3 + sliders + SDK de Facebook

Solución estilo UAQ

  • Hero con foto real + CTA único
  • Oferta educativa en grid visual de portada
  • Cards con extractos cortos y whitespace
  • Hero estático con mensaje y CTA
  • CTAs persistentes + sección Admisión en 4 pasos
  • Un HTML ligero, lazy loading, mobile-first
